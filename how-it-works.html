Under the hood

How the Simulator Works

Your candidate is read by an AI acting as a nonpartisan polling analyst. It scores how well the candidate is built — never which politics they hold.

  1. 01
    You build a candidate. Eight fields: name, age, party, occupation before politics, home state, top issue, campaign slogan, and a 3–5 sentence description. The description does the most work.
  2. 02
    The profile is sent to the analyst. Your browser posts the candidate to a small server function. That function adds a secret API key and forwards the profile to OpenAI. The key never reaches your browser.
  3. 03
    The analyst reads and reasons. It judges clarity, credibility, relatability, memorability, and coherence — does the age, job, state, issue, and personality tell one consistent story?
  4. 04
    It reports back in structured form. Approval rating, head-to-head poll, support broken down by age, political lean, and location, plus strengths, weaknesses, and campaign events.
  5. 05
    The site checks the numbers. Before anything is displayed, the server verifies the percentages add to 100 and every voter group is present, repairing the response if the model drifts.
  6. 06
    You change one thing and run it again. That comparison — same candidate, sharper slogan or a different top issue — is where the actual learning happens.

Where the numbers come from

The analyst is explicitly instructed that no party, ideology, or issue position is more popular, more moral, or more electable than any other. Democrat, Republican, Independent, Libertarian, Green, and invented parties all start from the same place. A party label changes which voter groups start friendly or skeptical — it never changes the candidate's overall score. Two equally well-written candidates score equally well no matter what they believe.

What actually moves the number: whether the slogan is memorable, whether the old job supports the chosen issue, whether the description is specific instead of generic, and whether the pieces contradict each other. A nurse running on healthcare starts with earned authority. A nurse running on national security has to build it.

Never Identical

Run the same candidate twice and you will get a similar verdict with different wording, different events, and slightly different numbers — the same way two real pollsters disagree.

Nonpartisan by Design

The analyst is barred from praising or criticizing any real-world political position, naming any real politician, or treating one party as easier to win with than another.

Works Offline Too

If the AI cannot be reached, a built-in local model produces a full report using the same rules, so a classroom never gets stuck on a blank screen.

This is fiction

Every voter, poll, percentage, and campaign event in this site is invented. Nothing here describes, predicts, or comments on a real election, a real person, or a real political party. Real polling involves sampling thousands of actual people, weighting for turnout, and reporting a margin of error. This is a story generator that looks like a poll — useful for learning what the pieces of a campaign are, useless for predicting anything.
